# GenAI Notes

A static React + TypeScript site built with Vite. All data is hardcoded in the source — there is no backend or database.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build

```bash
npm run build    # static files output to dist/
npm run preview  # serve the built site locally
```

Deploy the contents of `dist/` to any static host.
